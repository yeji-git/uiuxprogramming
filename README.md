## ✨ 10주차 추가 및 수정된 주요 기능 (New Features & Navigation Overhaul)

9주차까지 구현한 폼 UI 및 입력 검증 기능에 이어, **10주차 내비게이션 UI와 정보 탐색 설계 원칙**을 적용했습니다.

1. **서비스 맞춤형 상단 내비게이션 구성 (`nav`, `ul`, `li`):**
   - 발표 훈련 예제를 탈피하여, '게임 수집가' 서비스에 적합한 주요 목적지(`오늘의 추천`, `서재 현황`, `내 게임 서재`, `게임 추가`, `소식 받기`)를 구조화된 내비게이션으로 연결했습니다.
2. **현재 위치 실시간 표시 및 접근성 (`aria-current`):**
   - 주소창의 해시 값(`window.location.hash`) 변화를 감지하여 현재 보고 있는 영역과 일치하는 메뉴에 `.is-current` 스타일과 `aria-current="page"`를 적용합니다. 브라우저 뒤로 가기나 새로고침 시에도 위치가 완벽히 동기화됩니다.
3. **서재 목록 상태 필터 및 빈 상태 안내 (`aria-pressed`):**
   - '전체', '플레이 중', '완결' 3가지 필터 버튼을 제공하여 사용자가 원하는 상태의 게임 목록만 골라볼 수 있습니다.
   - 선택된 상태에 맞는 항목 수 실시간 안내와 함께, 결과가 없을 경우 **"선택한 상태의 게임이 없어요"**라는 전용 안내 문구를 출력합니다.
4. **반응형 모바일 메뉴 (햄버거 토글):**
   - 600px 이하의 좁은 화면에서는 가로 메뉴가 접히고 **[메뉴 열기/닫기]** 버튼이 활성화됩니다. `aria-expanded` 상태에 따라 메뉴가 펼쳐지며, 목록 중 하나의 목적지를 선택하면 자동으로 메뉴가 닫혀 쾌적한 탐색 경험을 제공합니다.

## 🧭 메뉴별 목적지 (Navigation Destinations)

| 메뉴 이름        | 연결된 섹션 ID (`href`) | 설명                                            |
| :--------------- | :---------------------- | :---------------------------------------------- |
| **오늘의 추천**  | `#recommend`            | 선호 장르 선택 및 오늘의 추천 게임 프리뷰 확인  |
| **서재 현황**    | `#stats`                | 전체 보유 게임 및 상태별 통계 수치 확인         |
| **내 게임 서재** | `#library`              | 보유한 게임 목록 탐색, 상태 필터링 및 상태 토글 |
| **게임 추가**    | `#add-game-section`     | 새로운 스팀 게임 제목과 장르를 직접 등록하는 폼 |
| **소식 받기**    | `#subscribe`            | 스팀 할인 및 위시리스트 알림 이메일 신청        |

## 🧪 기능을 확인할 수 있는 조작 순서 (Test & Operation Guide)

1. **메뉴 이동 및 현재 위치 확인:**
   - 상단의 **[내 게임 서재]** 메뉴를 클릭합니다. 주소창이 `#library`로 바뀌며 해당 영역으로 스크롤되고, 메뉴에 파란색 강조 표시가 나타나는지 확인합니다.
2. **서재 목록 필터 조작:**
   - 내 게임 서재 영역 상단의 **[완결]** 필터 버튼을 클릭합니다. '하데스'와 같이 완결 상태인 게임 카드만 필터링되어 나타나며, 버튼의 파란색 활성화 상태와 `aria-pressed="true"` 변경을 확인합니다.
3. **모바일 메뉴 열고 닫기 테스트:**
   - 브라우저 창 크기를 모바일 크기(600px 이하)로 줄이거나 개발자 도구의 기기 모드(예: iPhone, 390px)를 켭니다.
   - 우측 상단의 **[메뉴 열기]** 버튼을 클릭하여 세로형 메뉴가 펼쳐지는지 확인하고, **[오늘의 추천]**을 누르면 해당 위치로 이동하면서 메뉴가 자동으로 닫히는지 검증합니다.
4. **새 게임 등록 및 연동 확인:**
   - '게임 추가' 영역에서 제목(예: 엘든링)과 장르를 입력 후 서재에 추가해 전체 보유 게임 수와 목록에 즉시 반영되는지 확인합니다.
