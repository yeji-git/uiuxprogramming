# 🎮 게임 수집가 (Steam Game Collector) - 중간 프로토타입

> 당신의 취향에 맞는 스팀 게임을 추천하고 서재를 관리해 주는 인터랙티브 웹 서비스입니다.

---

## ✨ 7주차 대비 추가된 새로운 기능 (New Feature)

7주차 기본 인터랙션(탭, 테마 전환, 글자 수 표시, 서재 상태 변경)에 이어, 사용자가 보유하거나 플레이하고 싶은 **새로운 스팀 게임을 서재에 직접 입력하여 동적으로 추가하고 실시간 통계(보유 게임 수)를 연동하는 기능**을 추가했습니다.

---

## 🧭 사용자 흐름 및 인터랙션 시나리오 (User Flow & Scenarios)

1. **사용자 행동:** 메인 페이지 하단의 '내 서재에 게임 직접 추가하기' 영역에서 게임 제목과 장르를 입력하고 [서재에 추가] 버튼을 클릭한다.
2. **조건 검사 (오류 분기):**
   - **오류 경로:** 게임 제목을 입력하지 않고 버튼을 누르면 `alert("등록할 게임 제목을 입력해 주세요.")` 경고창이 뜨고 입력창으로 포커스가 이동한다.
   - **성공 경로:** 올바른 제목과 장르가 입력되면 새로운 게임 카드가 서재 목록 최상단에 생성된다.
3. **화면 반응 및 피드백:**
   - 상단 안내 메시지(`addGameMessage`)가 초록색 성공 스타일(`is-success`)로 바뀌며 등록 완료 문구가 출력된다.
   - 상단 '서재 현황'의 '전체 보유 게임' 숫자가 실시간으로 `1증가`하여 반영된다.
   - 새로 생성된 카드 내의 [상태 변경] 버튼을 통해 즉시 '플레이 중'과 '완결' 상태를 토글할 수 있다.

---

## 🧪 테스트 결과 (Test Results)

- **정상 경로 테스트:** 제목에 "엘든링", 장르에 "액션 / RPG"를 입력 후 추가 버튼을 클릭했을 때, 서재 목록에 새 카드가 정상 추가되고 '전체 보유 게임' 카운트가 `124개 -> 125개`로 정확히 갱신되는 것을 브라우저에서 확인했습니다.
- **오류 경로 테스트:** 제목을 빈 칸으로 둔 채 버튼을 눌렀을 때, 유효성 검사 조건에 걸려 안내 얼럿(Alert)이 출력되고 입력창에 포커스가 유지되는 것을 검증했습니다.
- **반응형 테스트:** 데스크톱(1100px) 및 모바일(390px) 뷰포트에서 입력 폼과 버튼이 겹치거나 화면 밖으로 밀리지 않고 유연하게 배치되는 것을 확인했습니다.
