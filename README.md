# 🎮 게임 수집가 (Steam Game Collector)

> 당신의 취향에 맞는 스팀 게임을 추천하고 서재를 관리해 주는 인터랙티브 웹 서비스입니다.

---

## 🛠️ 주요 구현 기능 (이벤트 및 동적 UI)

서비스 내에서 **click, input, change** 이벤트 및 탭 전환 기능을 구현하여 사용자 경험을 향상했습니다.

1. **click 이벤트 (알림 설정 및 테마 전환)**
   - **이메일 알림 신청**: 유효성 검사 통과 시 저장 상태(`isSaved = true`)로 전환되며, 문구가 *"알림 설정이 저장되었습니다."*로 바뀌고 버튼이 비활성화(`저장됨`)됩니다.
   - **화면 테마 변경**: 버튼 클릭 시 `body` 요소에 `dark` 클래스를 토글하여 어두운 테마와 밝은 테마 간의 전환이 이루어집니다.

2. **input 이벤트 (실시간 글자 수 카운팅)**
   - **사용자 이름 입력**: 사용자가 입력창에 텍스트를 입력할 때마다 실시간으로 글자 수를 계산하여 `0 / 10` 형태로 화면에 반영합니다.

3. **change 이벤트 (서비스 이용 안내 동의 확인)**
   - **이용 동의 체크박스**: 체크박스 선택 여부(`change`)에 따라 안내 문구의 스타일과 내용이 바뀌며, 하단의 **"서비스 시작하기"** 버튼의 활성화/비활성화 상태가 동적으로 제어됩니다.

4. **탭 UI 컴포넌트 (서비스 정보 전환)**
   - **주요 기능 탭 (`맞춤형 추천`, `서재 관리`, `할인 및 소식`)**: 세 가지 탭을 통해 페이지 이동 없이 주요 기능 정보를 유연하게 전환하여 확인할 수 있도록 구현했습니다.

## 📱 반응형 화면 변화 (Layout & Breakpoints)

다양한 디바이스 환경에서 최적의 가독성과 사용성을 제공하기 위해 반응형 레이아웃을 적용했습니다.

- **1100px (데스크톱 환경)**:
  - 넉넉한 최대 너비 안에서 좌우 2열 레이아웃(오늘의 추천), 그리드 카드, 가로형 내비게이션 메뉴가 조화롭게 배치됩니다.
- **768px (태블릿 및 소형 화면)**:
  - 미디어 쿼리를 통해 내비게이션, 폼, 기능 카드, 탭 메뉴 등이 세로 방향(`flex-direction: column`)으로 전환되어 모바일 화면에 최적화됩니다.
- **390px (모바일 환경)**:
  - 체크박스 영역(`agree-row`)에 유연한 너비 처리와 단어 줄바꿈(`min-width: 0`, `word-break: keep-all`)을 적용하여, 좁은 화면에서도 글자가 찌그러지거나 화면 밖으로 벗어나는 현상 없이 깔끔하게 정렬됩니다.

## 🧪 테스트 결과

- **이벤트 동작 테스트**:
  - 이메일 빈 값 입력 시 경고창(`alert`) 출력 및 포커스 이동 정상 작동 확인.
  - 테마 전환, 글자 수 카운트, 이용 약관 동의에 따른 버튼 활성화 상태 즉시 반영 확인.
  - 탭 클릭 시 선택된 탭(`is-active`)과 연결된 패널 외의 요소들이 `hidden` 처리되며 정상적으로 전환됨을 확인.
- **반응형 화면 테스트 (1100px / 768px / 390px)**:
  - 크롬 개발자 도구를 활용해 각 브레이크포인트에서 가로 스크롤 발생 없이 레이아웃이 유연하게 대응되는지 테스트 완료.
  - 모바일(390px) 환경에서 긴 텍스트와 체크박스 레이블이 영역을 벗어나지 않고 줄바꿈 처리되는 것을 최종 검증함.
