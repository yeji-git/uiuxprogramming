# 🎮 게임 수집가 (Steam Game Collector)

> 당신의 취향에 맞는 스팀 게임을 추천하고 서재를 관리해 주는 인터랙티브 웹 서비스입니다.

---

## 🧭 사용자 흐름 (User Flow)

- **사용자:** 보유 중인 스팀 게임의 플레이 기록과 진행 상태를 간편하게 관리하고 싶은 유저
- **서비스 목적:** 내 게임 서재에서 플레이 중인 게임의 상태를 직관적으로 변경하고 기록을 최신화한다.
- **완료 조건:** 상태 변경 후 카드의 시각적 스타일 변화와 안내 문구를 통해 변경 결과를 확인하고 상태 업데이트를 완료한다.

1. **진입:** 메인 페이지의 '내 게임 서재' 섹션으로 이동한다.
2. **입력:** 관리하고 싶은 게임 카드의 '상태 변경' 버튼을 누른다.
3. **상태 변경:** 현재 '플레이 중'인 게임을 '완결' 상태로 전환한다.
4. **확인:** '완결' 텍스트와 상단 안내 메시지를 통해 변경된 내용을 검토한다.
5. **완료(초기화):** 업데이트된 서재 상태를 최종 확인하고, 필요할 경우 다시 버튼을 누르면 '플레이 중' 상태로 되돌릴 수 있다.

---

## 인터랙션 시나리오

| 행동 (Action)             | 이벤트 · 조건 (Event & Condition)      | 화면 반응과 다음 상태 (Response & State)                                                  |
| :------------------------ | :------------------------------------- | :---------------------------------------------------------------------------------------- |
| **상태 변경 버튼 클릭**   | `click` · 현재 '플레이 중' 상태인 카드 | 클래스(`is-completed`)가 추가되며 카드가 초록색 테마로 바뀌고 텍스트가 '완결'로 전환된다. |
| **상태 변경 버튼 재클릭** | `click` · 현재 '완결' 상태인 카드      | 클래스가 제거되며 원래의 서재 테마로 돌아오고 텍스트가 '플레이 중'으로 전환된다.          |

## 테스트 결과 (Test Results)

- **정상 경로 테스트:** 버튼 클릭 시 `closest()`를 통해 올바른 게임 카드를 탐색하고, 상태 텍스트와 안내 문구가 정확하게 연동되어 바뀌는 것을 확인했습니다.
- **스타일 및 반응형 테스트:**
  - 데스크톱(1100px), 태블릿(768px), 모바일(390px) 환경에서 서재 그리드 카드와 버튼이 가로 스크롤 없이 유연하게 배치되는 것을 검증했습니다.
  - 다크모드(`body.dark`)에서도 완결 상태의 카드 배경색과 텍스트 가독성이 유지되도록 스타일을 적용했습니다.
