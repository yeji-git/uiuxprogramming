## 3주차 CSS 수정 및 시각적 구조 변경 기록

### 1. CSS 수정 이유

- **시각적 위계 명확화**: 사용자가 페이지에 접속했을 때 메인 제목(h1), 섹션 제목(h2), 카드 제목(h3)의 중요도를 직관적으로 구분할 수 있도록 폰트 크기와 여백(margin/padding)을 체계적으로 조정했습니다.
- **사용자 경험(UX) 및 인터랙션 강화**: 입력창과 버튼, 내비게이션 링크에 `hover`, `active`, `focus` 스타일과 `transition` 효과를 적용하여 사용자의 입력 및 클릭 상태를 명확한 피드백으로 제공하고자 했습니다.

### 2. 시각적 구조 변경 사항

- **Flexbox 레이아웃 적용**: '오늘의 추천 받아보기' 섹션과 '주요 기능', '내 서재 현황', '내 게임 서재' 영역을 Flexbox 기반의 가로 정렬 카드로 배치하여 전달력을 높였습니다.
- **접근성 강화**: 키보드 `Tab` 키로 요소를 이동할 때 현재 위치를 명확히 알 수 있도록 인디고 톤의 `outline` 포커스링 스타일을 일관되게 부여했습니다.
