## ✨ 9주차 대비 추가된 새로운 기능 (New Feature & UX Overhaul)

기본 인터랙션(탭, 다크모드 테마 전환, 글자 수 표시, 서재 상태 변경)에 이어, **9주차 폼 UI 및 입력 경험 설계 원칙**을 전면 적용했습니다.

1. **지능형 폼 UI 및 접근성 구조 (`aria-describedby`):**
   - 입력 필드와 도움말, 실시간 글자 수, 오류 메시지 영역을 `aria-describedby`로 명확하게 연결하여 스크린 리더와 웹 표준 접근성을 준수합니다.
2. **조건부 입력 영역 제어 (`aria-controls`, `aria-expanded`, `hidden`):**
   - "DLC(확장팩)도 함께 플레이 중인가요?" 체크박스 선택 여부에 따라 하위 상세 옵션 영역이 나타나고 숨겨지며, 숨겨진 항목은 키보드 포커스(Tab 이동)와 제출 데이터에서 완전히 배제됩니다.
3. **실시간 유효성 검증 및 입력 상태 피드백:**
   - 타이핑할 때마다 실시간 글자 수가 갱신되며, 2글자 이상 입력 시 초록색 테두리와 성공 안내(`is-valid`)로 즉각적인 피드백을 제공합니다.
4. **통합 Submit 검증 및 에러 핸들링 (비동기 저장 시뮬레이션):**
   - 유효성 검사 실패 시 첫 번째 오류 입력칸(`[aria-invalid="true"]`)으로 초점이 자동 이동합니다.
   - 저장 중에는 `aria-busy="true"` 상태를 통해 중복 제출을 막고 버튼을 잠급니다.
   - URL 파라미터(`?save-error=1`)를 통해 **저장 실패 시뮬레이션**을 테스트할 수 있으며, 실패 시에도 사용자가 입력한 데이터가 유실되지 않고 보존되어 다시 시도할 수 있습니다.

## 🧭 사용자 흐름 및 인터랙션 시나리오 (User Flow & Scenarios)

1. **사용자 행동:** 메인 페이지 하단의 '내 서재에 게임 직접 추가하기' 영역에서 게임 제목과 장르를 입력하고 [서재에 추가하기] 버튼을 누른다 (또는 Enter 입력).
2. **조건 검사 (오류 분기):**
   - **오류 경로:** 제목을 2글자 미만으로 입력하거나 비워둔 채 제출하면, `aria-invalid="true"` 속성이 부여되면서 빨간색 에러 문구와 테두리(`has-error`)가 표시되고, 첫 번째 오류 입력칸으로 초점이 이동한다.
   - **성공 경로:** 올바른 제목이 입력되면 '등록 중…' 상태를 거쳐 새로운 게임 카드가 서재 목록 최상단에 생성된다.
3. **화면 반응 및 피드백:**
   - 상단 '서재 현황'의 '전체 보유 게임' 숫자가 실시간으로 `1증가`하여 반영된다.
   - 새로 생성된 카드 내의 [상태 변경] 버튼을 통해 즉시 '플레이 중'과 '완결' 상태를 토글할 수 있다.
   - 새 계획(입력)을 다시 시작할 때 버튼 한 번으로 입력값과 에러 상태가 모두 깨끗하게 초기화된다.

## 🧪 테스트 결과 (Test Results)

- **정상 경로 테스트:** 제목에 "엘든링", 장르에 "액션 / RPG"를 입력 후 추가 버튼을 클릭했을 때, 서재 목록에 새 카드가 정상 추가되고 '전체 보유 게임' 카운트가 `124개 -> 125개`로 정확히 갱신되는 것을 브라우저에서 확인했습니다.
- **오류 및 초점 이동 테스트:** 빈 값이나 1글자("A")로 제출했을 때, 유효성 검증 규칙에 걸려 에러 메시지가 출력되고 포커스가 해당 입력칸으로 정확히 이동하는 것을 검증했습니다.
- **에러 실패 테스트 (`?save-error=1`):** 주소창 뒤에 `?save-error=1`을 붙여 강제 실패 상황을 연출했을 때, 입력값이 지워지지 않고 그대로 유지된 채 "저장하지 못했습니다. 다시 시도해 주세요"라는 안내와 함께 재시도가 가능한 것을 확인했습니다.
- **반응형 테스트:** 데스크톱(1100px) 및 모바일(390px) 뷰포트에서 입력 폼과 레이아웃이 찌그러짐 없이 유연하게 배치되는 것을 확인했습니다.
